# Workplace Nutrition Programme — Client Records

Shared record system for the Workplace Nutrition Programme.

- `clients/<client-ref>/` — enrolled employee profile records
- `standards/` — approved programme standards (read-only)
- `schedules/<client-ref>/` — day-type declarations
- `handover/` — coach handover notes and cycle instructions
- `submissions/` — completed daily target records filed by coaching staff

Programme standard currently in force: **Revision 7.2**.
